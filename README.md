# Dreamy-Weather
A dreamy and artistic weather website built using HTML, CSS, and JavaScript. 
# ☁ Dreamy Weather

> *Your personal sky diary. A little poetry in the sky ✦*

**Live demo:** https://prachisharma7730-star.github.io/Dreamy-Weather/

## About

Dreamy Weather is a simple, aesthetic weather web app for people who find magic in ordinary days. Instead of showing only numbers and charts, it presents the weather of any city as the "mood of the sky".

Type a city name, tap **Find My Sky**, and see what the weather is like there right now.

## Features

- 🌍 Search the weather of any city in the world
- 🌤 Live weather data from the OpenWeather API
- ✨ Soft, dreamy, poetic design
- 📱 Responsive layout for mobile and desktop

## Tech Stack

- HTML5
- CSS3
- JavaScript
- [OpenWeather API](https://openweathermap.org/)
- Hosted on GitHub Pages

## How to Use

1. Open the [live site](https://prachisharma7730-star.github.io/Dreamy-Weather/).
2. Enter a city name in the search box.
3. Click **Find My Sky ↗**.
4. See the current weather for that city.

## Run Locally

```bash
git clone https://github.com/prachisharma7730-star/Dreamy-Weather.git

```
